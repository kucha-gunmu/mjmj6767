COSMIX 是一个**可逆图像混淆**工具，以单个 HTML 文件的形式提供完整的浏览器端图形界面，
无需安装、无需后端、无需口令即可对图片做像素级打散与还原。混淆后的图像外观为噪点，
但携带的全部信息仍无损保留在 PNG 像素里，用同一工具即可逐位还原。

- **形态**：纯前端单文件 `cosmix.html`，双击即可在浏览器打开使用。
- **算法版本**：v3（与 Python 版 `cosmix/` 逐位兼容）。
- **输出**：始终为无损 PNG，原图的 `eXIf` / `iCCP` / `sRGB` 等元数据块一并保留。
- **支持输入**：PNG / JPG / WebP / BMP / GIF 首帧（PNG 走纯 JS 解码以保留元数据，其余由浏览器解码为 RGBA）。

---

## 一、功能概览

| 功能 | 说明 |
|------|------|
| 混淆 | 对输入图片执行「余弦概率 Feistel 置换 + 逐像素值扩散」，输出噪点化 PNG |
| 还原 | 对混淆图逆向处理，恢复原像素，并用指纹自检还原是否逐位正确 |
| 读取头信息 | 查看/编辑混淆时写入 PNG 的 `cosmix` 文本块（记录尺寸、变体、轮数等） |
| 统计特征 | 实时对比混淆前后的通道熵、左邻相关、平均绝对误差（MAE）、与原图相同像素占比 |
| 变体 / 轮数 | 可调 Feistel 轮数（4–32，默认 8）与变体名（默认 `default`） |
| 元数据保留 | 输出 PNG 时原样搬运辅助块，聊天软件即使剥掉元数据也能用默认参数兜底还原 |

---

## 二、使用方式

### 混淆

1. 用浏览器打开 `cosmix.html`；
2. 点击或拖入一张图片；
3. 按需设置 **Feistel 轮数** 与 **变体名**（可留默认）；
4. 点击 **混淆**，等待进度条完成；
5. 在「下载」区保存为 `<原名>.cosmix.png`（请以文件形式发送，避免被二次压缩）。

右侧预览会同步显示混淆结果，「统计特征」表会量化打散效果（熵升高、相邻相关性趋零）。

### 还原

1. 打开同一页面，拖入 `.cosmix.png`（或任何被混淆过的图片）；
2. 若文件仍带 `cosmix` 头信息，工具会自动识别变体与轮数；若元数据已被剥离，
   使用与混淆时一致的轮数与变体（或退回默认 `default` + 8 轮）即可；
3. 点击 **还原**，得到逐位一致的原始像素，并下载 `<原名>.restored.png`。

## 三、算法原理

COSMIX 的核心是把「重排像素位置」与「打散像素数值」两步叠加，二者均由确定性伪随机
过程生成，因而完全可逆。整体管线如下：

```
输入 RGBA ──► 余弦概率 Feistel 置换（位置重排）──► 逐像素值扩散（数值打散）──► 噪点 PNG
噪点 PNG ──► 反值扩散 ──► 逆 Feistel 置换（位置还原）──► 指纹自检 ──► 原始 RGBA
```

### 1. 密钥派生（KDF）

- 主密钥由 `BLAKE2b(固定种子 + "|" + 变体名)` 派生（`deriveMaster`）。
- **不需要口令**：算法本身就是全部参数，变体名是公开标签而非秘密。
- 子密钥通过 `HMAC-SHA256` 按标签派生：`perm/phase`、`perm/round/NN`、`diff/rotate`、`diff/xor`。

### 2. 余弦概率 Feistel 置换

- 以像素总数 `n` 决定 Feistel 的分组半长（`permutationParams` 取 2 的幂）。
- 每一轮的置换表 `makeRoundTable` 结合 **余弦权重**：
  `cosineWeight(t, phase) = 0.5·(1 + cos(2π(t + phase)))`，
  把 BLAKE2b 输出的局部相位与全局相位混合后调制置换倾向，使打散在统计上更均匀。
- 采用 **cycle-walking** 保证落在 `[0, n)` 内且严格双射，因此可精确逆向（`feistelDecrypt`）。
- 默认 8 轮，可调 4–32。

### 3. 逐像素值扩散

- 用 `lowbias32` 计数器密钥流（`keystream`）生成两类序列：
  通道**旋转量** `rot`（在 R/G/B 之间循环移位）与**异或掩码** `ks`。
- 混淆：`mixed[t] = V[P[t]]` 先置换，再对每像素做通道旋转 + 异或；还原为对称逆运算。
- 处理分块进行（每块 `2^16` 像素），每块让出一次事件循环，大图界面不假死、进度条可动。

### 4. PNG 编解码

- 纯 JS 实现 PNG 解码（`decodePNG`）：支持 8-bit 非隔行的灰度/RGB/调色板/带 Alpha 等颜色类型，
  完整还原 5 种行过滤器（None/Sub/Up/Average/Paeth）。
- PNG 编码（`encodePNG`）：统一输出 RGBA（color type 6），并把原图的辅助块原样搬回，
  `cosmix` 头信息以 `tEXt` 文本块写入。
- zlib 压缩/解压借助浏览器原生 `CompressionStream` / `DecompressionStream`。

### 5. 头信息与自检

- 混淆时写入 `cosmix` 文本块，字段包括：
  `magic`、`v`（版本）、`w/h`（尺寸）、`variant`（变体）、`rounds`（轮数）、
  `alpha`（是否参与通道旋转）、`sum`（原图像素指纹）、`src_format`、`meta`。
- `sum` 取 `BLAKE2b(像素)` 前 16 字节，用于还原后校验像素是否被改动（重编码/缩放/裁剪会导致指纹不符）。
- 超过 8 MB 像素的超大图跳过指纹计算（BigInt 版 BLAKE2b 过慢），此时还原不做指纹校验。

## 四、统计指标说明

「统计特征」表对比混淆前后的图像统计量，用以量化打散效果：

- **熵 R/G/B**：各通道香农熵，混淆后应接近满值（更均匀、更随机）。
- **左邻相关 R/G/B**：相邻像素相关系数，混淆后趋近 0（消除空间结构）。
- **平均绝对误差（MAE）**：混淆图与原图逐通道平均像素差，越大打散越彻底。
- **与原图相同像素**：混淆后仍与原图一致的像素占比，越小说明打散越充分。

## 五、版本与兼容性

- **v3（当前）**：无口令，主密钥 = `BLAKE2b(固定种子 + 变体名)`，密钥流为 `lowbias32` 计数器模式。
- **v2（兼容存量）**：使用旧种子与 BLAKE2b 计数器密钥流，还原时按头信息 `v=2` 自动切换。
- **v1（需口令）**：本工具不再支持，提示改用带口令的备份版本还原。

页面通过 `globalThis.COSMIX_CORE` 导出全部核心函数（哈希、KDF、置换、扩散、PNG 编解码、
`mixImage` / `restoreImage` / `analyse` 等），便于在浏览器控制台或自动化测试中直接调用。

---

## 六、限制与注意事项

- 仅支持 **8-bit 位深、非隔行** 的 PNG；隔行（Adam7）或 16-bit PNG 会拒绝处理。
- 非 PNG 输入会被浏览器解码为 RGBA，其原始元信息无法保留。
- 还原必须使用与混淆时**一致的轮数与变体名**，否则置换与密钥流对不上。
- 若图像被聊天软件缩放、裁剪或二次有损压缩，像素已改变，还原会得到错误结果（指纹校验会提示不符）。
- GIF / 视频的逐帧处理不在本前端文件内，需要另行借助本地后端完成。
